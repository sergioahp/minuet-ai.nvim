Codestral / completion experiment / October 2026

Does text after the cursor cause repetition?

Not consistently in this test. Codestral sometimes generated text already after the cursor, but it did so at similar overall rates when that text was removed. The text after the cursor could still steer what it wrote.

01 / The setup

A completion in the middle

The model was asked to fill in text at a cursor position, with text before it and, sometimes, text after it.

BeforeText leading up to the cursor
InsertionWhat the model generates
AfterThe supplied suffix

A suffix is the text supplied to the model as the text after the cursor. A fixture is one fixed example and cursor position.

Four versions of the text after

For each of eight selected Lua and TeX examples, the benchmark tried:

  • Original: the actual following text
  • Empty: no following text
  • Newline: just a line break
  • Changed: a plausible alternative following text

Each combination was called nine times. All 288 calls succeeded, using Codestral's fill-in-the-middle endpoint with a 64-token output cap.

Overlap is a clue, not a verdict. Common syntax or a natural equation ending can appear even when the model never saw the following text. A match does not establish that an edit would be wrong; shorter repetitions can also fall below the 12-character cutoff.

03 / What the examples reveal

The suffix can steer the answer

The aggregate hides different behaviors. In one example, changing the following text changed the tail the model generated; in another, the same ending appeared even without any suffix.

TeX operator

A changed ending was followed

All 9 changed-suffix completions emitted its alternative operator and equation tail. The original tail also appeared in all 9 empty-suffix calls, so it could be prompted by the text before the cursor alone.

TeX expression

A natural ending appeared everywhere

All 9 completions in each condition supplied the same diagnostic equation ending. Its appearance here cannot be attributed to the original suffix.

Lua newline

Some existing text reappeared

7 of 9 original-suffix completions reached the start of a later class annotation; none did so under the empty or newline conditions. The match was only a partial annotation.

04 / Practical takeaway

Inspect the edit before changing the rule

The test does not support a blanket claim that supplying a suffix increases repetition. It does show that the suffix can influence a completion, and that some completions reach text already present after the cursor.

Keep the scope in mind

  • The eight examples were selected, not randomly sampled from everyday editing. Nine repeats of one position are not nine independent editing situations.
  • Many responses hit the 64-token cap, which can truncate output. A token is a unit of text used by the model, not necessarily a whole word.
  • The overlap measure does not check whether the resulting document is valid. Automatically stripping matching text could remove valid syntax or a useful short insertion.
  • The model was called as codestral-latest, an alias that can change. Different stop settings or an editor that accepts only the first line could produce a different visible result.
