Codestral / cursor completion experiment / October 2026

What did Codestral write at the cursor?

Text after the cursor sometimes steered the completion, but it did not consistently increase repeated text. The model also produced the same equation ending when no following text was supplied. The actual requests and completions below make that distinction visible.

01 / See the completions

One cursor, different text after it

A prefix is the text before the cursor. A suffix is the text supplied after it. Codestral generated an insertion between them. The cursor markers below are visual aids; they were not sent in the requests. Each output shown is from a named call, with its raw request and response linked.

A short insertion can be useful

02 / The measurement

Overall overlap was similar with and without the original suffix

For every call, the analysis compared the generated text with the original suffix, even when the model was given an empty, newline, or changed suffix. A match means at least 12 consecutive characters appeared in both after whitespace was collapsed; it could occur anywhere in the completion. It does not judge the resulting edit.

Original minus empty: -1.4 percentage points. Original minus newline: +1.4 points. Original minus changed: +16.7 points. Cluster-resampled 95% intervals were broad: -43.1 to +36.1, -41.7 to +43.1, and -5.6 to +44.4 points, respectively.

How to read this: the overall counts do not support a general claim that supplying the original suffix increases text overlap. The TeX example shows that the suffix can still steer a particular completion. A text match alone cannot tell whether an editor would produce a bad edit.

03 / Scope

What this test can and cannot say

How it ran

Five TeX and three Lua cursor splits were tried with the original following text, no following text, a single newline, and a plausible changed version. Each split and condition was called nine times with codestral-latest, temperature 0, no stop sequences, and a 64-token output cap. All 288 calls succeeded.

The TeX inputs adapt an Overleaf example; the Lua inputs came from this repository. The changed suffixes were written for the benchmark.

What the counts miss

Some matches are natural code or equation endings. Some copied delimiters are too short to reach 12 characters. Many completions continued past the intended insertion and hit the 64-token cap. The metric compares text; it does not validate a finished file or model an editor accepting only the first line.

Limits on the conclusion

  • These eight splits were selected examples, not a random sample of editing. Nine repeats of the same split are not nine independent editing situations.
  • Effects varied strongly by split. The uncertainty intervals above resample the eight splits, so the overall difference is imprecise.
  • codestral-latest is an alias and can change. Different stop settings or acceptance behavior could change what users see.
  • Reported usage was 13,887 input and 14,076 output tokens. At the published rates used in the run, estimated usage cost was $0.0168345; this is not an account invoice.
